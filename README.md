# CodeAlpha_Web-Scraping
Developed a Python-based web scraping project using BeautifulSoup and Pandas to collect book details, clean the data, and analyze prices, rating, and availability. 
# Book Price & Rating Web Scraping Analysis

## Project Overview

This project uses Python and BeautifulSoup
to scrape book information from a public
practice website.

## Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas
- Matplotlib
- Jupyter Notebook

## Data Collected

- Book Name
- Price
- Rating
- Availability
- Product URL

## Analysis

The dataset was analyzed to identify:

- Average book price
- Highest priced books
- Lowest priced books
- Rating distribution
- Average price by rating

## Outcome

Created a structured CSV dataset containing
scraped book information for further analysis.
